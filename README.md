# Atividades Práticas com Raspberry Pi

Repositório desenvolvido para a disciplina como parte das atividades práticas com Raspberry Pi. O projeto reúne duas aplicações com interface web e backend em Python, utilizando a Raspberry Pi para apresentar informações do sistema e realizar verificações da rede local.

## Atividades desenvolvidas

### Atividade 1 — Painel Web de Status da Raspberry Pi

Aplicação para visualizar informações do sistema da Raspberry Pi por meio de um painel web. O backend coleta os dados do equipamento e disponibiliza as informações para o frontend através de uma API.

**Principais funcionalidades:**
- Visualização de informações do sistema.
- Consulta de dados por meio de uma API.
- Apresentação das informações em uma interface web.

### Atividade 2 — Monitor de Rede Local

Aplicação para acompanhar as configurações de rede da Raspberry Pi e verificar a conectividade com diferentes destinos.

**Principais funcionalidades:**
- Exibição das informações de rede do equipamento.
- Consulta da interface de rede, endereço IP, máscara, gateway e DNS.
- Testes de conectividade com o gateway, um dispositivo da rede local e um destino externo.
- Apresentação dos resultados dos testes de conexão.

## Tecnologias utilizadas

## Execução

Cada atividade possui seu próprio backend e frontend. Para executar uma delas, consulte o README específico da atividade, onde estão descritos os arquivos utilizados e os procedimentos de execução.

## Objetivo

O objetivo do trabalho é colocar em prática conceitos de programação em Python, desenvolvimento de interfaces web, comunicação entre frontend e backend e utilização da Raspberry Pi para monitoramento do sistema e da rede.
